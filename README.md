# La Gran Carrera Revelación 🏁💙💗

Carrera de karts simulada para una revelación de género. El ganador se elige en secreto antes de empezar y la carrera siempre termina con ese resultado (con rebases, objetos y una llegada de foto).

## Cómo usarla
1. Abre `index.html` en Chrome o Edge (doble clic; no requiere instalación). Conecta la laptop a la TV o al proyector.
2. **Antes de que lleguen los invitados**: presiona `S` (o el engrane ⚙ casi invisible abajo a la derecha) → elige quién gana, los nombres y las vueltas → Guardar.
   - Atajo discreto: en la portada, tecla `1` = gana niño, `2` = gana niña (solo aparece un “✓”).
3. Presiona `F` para pantalla completa y luego **¡ARRANCAR!** (o Enter).
4. Al final aparece la revelación con confeti. `R` o “Otra vez” regresa a la portada.

Teclas: `F` pantalla completa · `M` silenciar · `Esc` volver a la portada.

> Consejo: ábrela una vez con internet para que se guarden las tipografías; después funciona sin conexión.
> Prueba interna: en la consola del navegador, `__simTest(300)` simula 300 carreras y confirma que siempre gana el elegido.
